The participant-level dataset used for this analysis is restricted and is not distributed with this public website repository.

The file contains individual-level health, demographic, behavioural, medication, socioeconomic, and polygenic-risk variables. Whether any subset may be shared depends on the original consent, data-use agreement, ethics approval, and applicable institutional requirements; repository publication should not be assumed to be permitted.

For local reproduction by an authorised researcher, store the dataset outside the repository and provide its path through the `CDP_DATA_PATH` environment variable. The analysis rejects paths inside the website project. Do not copy or commit the participant-level file anywhere in this repository.

Only variables required by the published analysis are loaded. Public outputs should contain aggregate summaries and model results rather than participant-level records.
